How It Works

From natural language instruction to verified PayPal payment settlement in three automated steps.

01

Chat to create the invoice

Simply tell the agent what to bill in plain English: "Invoice sarah@example.com $400 for logo design, due in 15 days". The agent uses PayPal Invoicing API v2 to create a draft and immediately dispatch a real PayPal Sandbox invoice.

02

Automatic reminders

When invoices pass their due date, our autonomous background chaser steps in. It evaluates overdue balances and dispatches up to 3 escalating reminder notes directly through PayPal (Friendly check-in → Firm follow-up → Urgent final notice).

03

Paid status updates through PayPal webhooks

When your client pays via PayPal, real-time webhooks (INVOICING.INVOICE.PAID) and background reconciliation verify the transaction, flip the dashboard badge to [PayPal Settled], and permanently halt the chaser.

Built With

Engineered for reliable agentic commerce with official PayPal APIs and robust guardrails.

💳
PayPal Invoicing API v2

Full lifecycle management: OAuth tokens, create draft, send, remind, cancel, get, and delete.

🪝
PayPal Webhooks

Real-time payment event streaming with cryptographic signature verification on incoming notifications.

🤖
LLM Tool Calling

OpenAI-compatible function calling with guardrails (mandatory fields, USD lock, $1,000 confirmation rule).

⚡
FastAPI & Python 3.11+

Asynchronous backend with SQLite persistence, concurrency locks, and per-IP rate limiting.
